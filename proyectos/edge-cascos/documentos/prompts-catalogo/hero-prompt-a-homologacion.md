tarjetas de homologación de este catálogo (imagen de referencia
adjunta como guía de estilo). Es una reproducción de un layout fijo:
lo ÚNICO que cambia es QUÉ DICE la lista y el banner de certificación.

- El lienzo final tiene que tener EXACTAMENTE la misma relación de
  aspecto que la tarjeta de referencia adjunta: rectángulo vertical
  angosto, aproximadamente 1 : 2 (alto ÷ ancho ≈ 2).
- ESTA TARJETA TIENE SOLO 2 ÍTEMS (la referencia tiene más). Aunque
  haya menos ítems, el lienzo NO CAMBIA: mismo ancho, mismo alto. Lo
  que se ajusta es el reparto interno: más aire parejo entre los
  renglones, siempre centrados como grupo en la zona gris.
- La cantidad de ítems NUNCA modifica las dimensiones del lienzo. El
  lienzo es una CONSTANTE, el reparto interno es la VARIABLE.
- ATENCIÓN, ESTE ERROR YA PASÓ EN OTRA TARJETA DE ESTE MISMO CATÁLOGO:
  el resultado salió estirado a una relación de 1 : 2,47 en vez de
