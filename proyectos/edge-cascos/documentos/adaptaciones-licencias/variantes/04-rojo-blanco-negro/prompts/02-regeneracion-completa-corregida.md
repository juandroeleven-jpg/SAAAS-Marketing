# PROMPT 2 — Regeneración completa desde cero (v3) · Variante 04 rojo/blanco/negro · Vista C trasera

**No es un parche al archivo fuente ni una edición sobre una imagen existente:**
es el prompt de generación completo, reescrito de cero, con las tres correcciones
que salieron de auditar el intento 1 (ver `../ESTADO.md` §§ 2-4) ya incorporadas.
Se usa para regenerar la vista desde el principio, no para corregir un resultado.

**Adjuntar 2 imágenes en este orden:** (1) `04-rojo-blanco-vista-c-ILUSTRACION.webp`
· (2) `00-kratos-real-trasera-CHECKPOINT.webp`.

## Qué cambió respecto de la versión anterior de este prompt

El prompt anterior (v2) se contradecía a sí mismo en **tres lugares distintos**,
no uno: pedía el sello "con el texto DOT" y a la vez decía "el sello no se dibuja",
y encima el checklist final volvía a pedir "el sello DOT está presente y legible".
Las tres menciones a "legible" sobre el sello se corrigieron a "forma correcta,
vacío por dentro" en esta versión.
